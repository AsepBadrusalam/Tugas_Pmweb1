Alur Kolaborasi Git

  1. Buat branch masing-masing: feature/halaman-anggota1 dan feature/halaman-anggota2
  2. Masing-masing commit + push di branch sendiri
  3. merge kedua branch ke main (pull request)
  4. Hasil akhir: 3 halaman dalam 1 web
